# ecef-coordinate-converter
This project converts geographic coordinates from Degrees, Minutes, Seconds (DMS) to Earth-Centered, Earth-Fixed (ECEF) Cartesian coordinates using Python and pyproj.
It also calculates the straight-line distance between two points using their ECEF coordinates.
Technologies: Python, Jupyter Notebook, pyproj
Note: Results depend on coordinate accuracy, the reference ellipsoid, and height assumptions.
